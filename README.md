Для того чтобы воспользоваться данным скриптом, выполните следующие шаги:


1. Установите необходимые зависимости:
Откройте терминал и выполните следующую команду для установки требуемых библиотек:
pip install requests beautifulsoup4 psycopg2


2. Настройте базу данных:
Установите и настройте pgAdmin4 или любой другой удобный инструмент для управления PostgreSQL.
Создайте локальную базу данных, где будут храниться данные об играх. Это позволит вам сохранять информацию
о скрапленных играх для дальнейшего использования.


4. Настройте скрипт:
Перед запуском бота убедитесь, что база данных настроена и подключена правильно в вашем коде.
В коде предусмотрена задержка между запросами, чтобы избежать блокировки со стороны сайта.
Имейте в виду, что на сайте может быть много игр, и процесс скрапинга займет некоторое время.
Задержка в несколько секунд между запросами помогает избежать проблем с частыми запросами к серверу.


6. Запустите скрипт:
Запустите скрипт и дождитесь завершения процесса скрапинга. Все найденные игры будут сохранены в базу данных.


7. Подключите бота к базе данных:
После того как все игры будут сохранены в базу данных.
ваш бот сможет предоставлять информацию об играх пользователям на основе данных из базы.
Теперь вы сможете запрашивать информацию об игре через Telegram и получать ее из базы данных.
